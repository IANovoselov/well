# well — моделирование и идентификация нефтяной скважины с ЭЦН

Научный прототип: имитационная модель скважины с установкой электроцентробежного
насоса (ЭЦН) и методы идентификации параметров пласта и насоса по данным телеметрии.

## Что внутри

- `src/well/domain/simulation/` — модель: пласт, насос, АГЗУ, измерительный канал (шум, квантование).
- `src/well/domain/identification/` — идентификация параметров (p_R, r_1, r_2, r_N, nn_1, nn_2)
  методом наименьших квадратов по отфильтрованным регрессорам.
- `src/well/visualization/` — графики (matplotlib и plotly).
- `src/well/experiments/` — ноутбуки с экспериментами.

## Установка

    pip install -e .

## Эксперименты

Ноутбуки лежат в `src/well/experiments/` и запускаются из корня проекта.
Одна симуляция на 45 000 шагов считается секунды, полные сетки экспериментов — минуты.

## Статус

Код в переходном состоянии: идёт рефакторинг к чистой архитектуре и подготовка
ML- и Flask-этапов.
